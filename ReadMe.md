# NimitAI Intern Assignment

## Overview
This project is a simple AI-powered web application that analyzes meeting transcripts and identifies key sales signals such as buying interest, objections, and confusion. The application also provides a one-line coaching tip for each detected signal.

## Features
- Paste a meeting transcript into a text area.
- Analyze the transcript using an LLM.
- Detect sales signals:
  - Buying Interest
  - Objections
  - Confusion
- Display results as cards containing:
  - Signal Type
  - Relevant Quote
  - Coaching Tip
